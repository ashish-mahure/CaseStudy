# NexaFlow Landing Page

## Project Overview
A polished marketing landing page for NexaFlow built in Next.js, React and TypeScript to match the supplied design reference as closely as possible while remaining production-ready and maintainable.

## Tech Stack
- Next.js
- React
- TypeScript
- CSS
- ESLint

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm start
```

## Implementation Notes
- Component structure keeps the page layout readable and organized across header, mock dashboard, section content, and footer.
- The page uses a mobile-first responsive strategy with desktop layout fidelity and smaller-screen adaptations for navigation, cards, and section spacing.
- The visual treatment is implemented with CSS gradients, borders, shadows, and lightweight HTML/SVG patterns instead of relying on external image assets.
- Semantic landmark elements, keyboard-accessible links, and visible focus states are included for accessibility.
- The page stays lightweight by avoiding unnecessary libraries and by using CSS-driven illustration instead of bulky asset dependencies.
